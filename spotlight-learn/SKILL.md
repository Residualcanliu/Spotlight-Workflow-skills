# Spotlight Learn — 仅思考模式

你已被 `/spotlight-learn` 命令调用。用户想要**仅启用思考逻辑**，不涉及任何文件夹操作。

## 执行流程

1. **加载主技能文件**：读取 spotlight 主技能文件。
   > `{项目目录}` 解析规则：优先检查 `~/.claude/skills/spotlight/SKILL.md`（已部署）；如果不存在，则查找当前工作目录或其父目录中的 `SKILL.md`（开发模式）。

2. **跳过安装检查**。不读取 `~/.spotlight_config.json`。不询问任何路径配置。

3. **仅启用以下模块**（主技能对应章节）：

   | 启用 | 章节 | 内容 |
   |------|------|------|
   | | §二 | 写作风格手册 — 三项铁律、五维风格框架、图片桥接规范 |
   | | §三 | 用户思维与决策模式 — 指令风格解读、决策节奏、验收标准 |
   | | §四 | 错误→正确路径 — officecli 避坑、文件操作避坑、理解偏差避坑 |
   | | §五 | 工具使用最佳实践 — officecli 命令速查、工具选择原则 |
   | | §七 | 核心铁律速查 — 15 条铁律 |
   | | §八 | 技能联动 — 关联其他 skill |
   | | §1.2-1.5 | 任务复杂度判断、迭代精炼、两阶段审批、文档编辑（不含 1.1 项目创建）。§1.5 文档编辑依赖 officecli，如未安装则自动降级为纯文本编辑；§1.4 两阶段审批需要 learn 复盘数据做风格参考，轻量模式下可能缺少风格基准 |

   | 不启用 | 章节 | 内容 |
   |--------|------|------|
   | [N] | §0 | 初始化设置 |
   | [N] | §1.1 | 项目创建工作流（改用当前目录） |
   | [N] | §六 | 复盘与持续学习（不写入 learn） |

4. **工作目录**：使用用户当前所在目录（`pwd`），而非 `{claudework_path}`。

5. **适用场景**：
   - 快速咨询（"这个怎么写？""帮我看看这段代码"）
   - 临时任务，不想关联到 claudework 项目体系
   - 在其他人的电脑上使用（不创建任何文件夹）
   - 用户明确只需要 AI 的思考和判断，不需要项目管理

> 详细避坑清单、工具速查、思维模式见同目录下的 `REFERENCE.md`。按需读取，无需一次加载。
