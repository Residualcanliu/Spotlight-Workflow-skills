# Spotlight Style — 写作风格来源切换

你已被 `/spotlight-style` 命令调用。用户想要**切换写作风格的来源**。

## 执行流程

1. **加载主技能文件**：读取 spotlight 主技能文件。
   > `{项目目录}` 解析规则：优先检查 `~/.claude/skills/spotlight/SKILL.md`（已部署）；如果不存在，则查找当前工作目录或其父目录中的 `SKILL.md`（开发模式）。

2. **读取当前配置**：
   - 读取 `~/.spotlight_config.json`
   - 如果配置文件不存在 → 告知用户先运行 `/spotlight-init` 完成初始化，退出
   - 检查 `writing_style_mode` 字段

3. **翻转模式并保存**：

   | 当前值 | 切换为 | 提示信息 |
   |--------|--------|---------|
   | `"blend"` 或 不存在 | `"learn_only"` | 已切换到纯学习模式。写作表达将完全基于本机 learn 复盘中总结的用户个人风格。Spotlight 内置写作铁律（十一项铁律、五维框架、图片桥接规范）不再生效。 |
   | `"learn_only"` | `"blend"` | 已切换回混合模式。写作表达为 Spotlight 内置风格与你的个人风格各 50%。 |

4. **保存配置**后结束。不需要执行任何其他任务。

5. **轻量模式兼容性检查**：如果切换到 `learn_only` 模式且当前 `mode` = `"lightweight"`，额外提示：
   > 当前为轻量模式，learn 复盘库未配置。纯学习模式需要 learn 复盘库来积累写作风格——风格观察不会被持久化，下次会话将从头开始。建议先运行 /spotlight-init 完成初始化。

## 模式说明

此命令只影响 §二（写作风格手册）的生效方式。其他模块（工作流、思维模式、避坑清单、工具速查）不受影响。

> 详细避坑清单、工具速查、思维模式见同目录下的 `REFERENCE.md`。按需读取，无需一次加载。
